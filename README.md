# cPanel to CWP transfer checklists

Reusable checklists for moving Joomla sites from cPanel to CWP (Control Web Panel).

- [Akeeba restore to CWP](akeeba-restore-to-cwp.md) — restore a Joomla site from an Akeeba backup onto a CWP account and verify it before public DNS cutover.
- [Domain hosting migration checklist](domain-hosting-migration-checklist.md) — DNS, website, FTP, and email checks when moving a domain between hosting servers.

These documents are generic steps. They contain no credentials, server addresses, or account details.
